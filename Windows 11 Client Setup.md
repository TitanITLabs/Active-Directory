##Virtual Machine Configuration
Here are the following specifications for the Windows Client

Wins11 Client1
- Role: Active Directory client workstation
- OS: Windows 11 Pro (Windows 11 Pro allows for remote connection using RDP as well as allowing for full drive encryption)
- RAM: 4 GB
- CPU: 3 vCPUs
- Disk: 20 GB
- Notes: Joined to the domain for user login and Group Policy testing
